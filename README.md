# Study02_ToDoList

하루 10~20개의 할 일을 카테고리별로 관리하고 진행률을 한눈에 보는 개인용 할 일 관리 웹 앱입니다.
순수 HTML·CSS·JavaScript로 만들며, 설치나 서버 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- 할 일 추가, 수정, 삭제
- 완료 체크 / 해제
- 카테고리 분류: 업무 · 개인 · 공부
- 전체 및 카테고리별 진행률 표시
- localStorage 자동 저장 (새로고침해도 데이터 유지)

## 기술 스택

- HTML5, CSS3, JavaScript (ES6+)
- 프레임워크·라이브러리·빌드 도구 없음
- 데이터 저장: 브라우저 localStorage

## 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/withsm77-blip/basic.git
   ```
2. `index.html` 파일을 더블클릭해 브라우저로 엽니다. 설치나 빌드는 필요 없습니다.

## 사용법

- 할 일을 입력하고 카테고리를 고른 뒤 **Enter** 또는 **추가**
- 체크박스로 완료 / 해제 — 완료된 일은 목록 아래로 이동
- 텍스트를 **더블클릭**하거나 **수정**을 눌러 편집 (Enter 저장, Esc 취소)
- 상단 탭으로 카테고리별 보기, **완료 항목 삭제**로 끝난 일 정리
- 제목 아래 **자동 / 1단 / 2단** 토글로 레이아웃 선택 (자동: 화면 폭 960px 이상이면 2단, 선택은 저장됨)
- 데이터는 브라우저 localStorage에 자동 저장 (같은 브라우저에서만 유지)
